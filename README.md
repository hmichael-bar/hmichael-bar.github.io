# hmichael-bar.github.io

Portfolio site for H. Michael Bar Bourenane: financial crime, sanctions and OSINT projects.

Code for every project: https://github.com/hmichael-bar/fincrime-portfolio

`index.html` is the published page. `tools/build_viz_data.py` injects the interactive chart data from the project outputs into `portfolio.html`, which `index.html` is generated from.
